## 배포 안내
기존 배포 파일은 로그인 없이 내려받을 수 있습니다. 게임별 파일·원본 해시·적용 방법은 각 저장소 README를 기준으로 합니다. 새 GitHub Releases는 별도 버전 기록에 추가합니다.

원본 ROM 및 게임 파일은 제공하지 않습니다.

## 관리 파일

**배포 설정:** Settings → Pages → Deploy from a branch → main /docs → Save
