Gens 2.14 → Gens KO 2.14 R2 작업 안내

Gens 2.14에 한글 메뉴와 편의 기능을 추가한 비공식 수정본입니다.

주요 변경
• 한글 메뉴·설정창, 키보드 / 게임패드 설정 개선
• ROM 처리 상한 6MB → 32MB, 피어솔라 매퍼 대응
• FF·REW·슬로우모션 및 속도 조절
• 기능마다 홀드 / 토글 선택 가능
• GLSL/GLSLP 셰이더와 기본 CRT·스캔라인 효과 추가
• 모니터 이동·창 전환 시 검은 화면·깜빡임 대응 경로 개선
• 게임 바로가기 실행, Alt / Esc로 메뉴 표시·숨기기
• 입력·저장·ROM 로딩·CPU 명령 등의 기존 오류 수정

키 설정
설정 → 키보드 / 게임패드 → ‘일괄 설정’을 누르고 안내 순서대로 입력하면 됩니다.
기본은 6버튼 패드입니다.

ABC = C X Z
XYZ = D S A
START = V / MODE = F
방향 = 방향키

Tab = FF (기본 홀드·4배속)
Backspace = REW (기본 홀드·2배속)
Space = 슬로우모션 (기본 토글·0.5배속)

설정 → 핫키 / 배속 / 되감기 설정에서 키·작동 방식·속도를 바꿀 수 있습니다.

현재는 시험판입니다. 변속 중에는 무음이며, 메가 CD·넷플레이의 되감기는 지원하지 않습니다.
Windows 실기·다중 모니터·게임별 호환성 확인은 진행 중입니다.

라이선스 안내
Gens 본체는 GNU GPL로 안내되어 있으나, 내장 Starscream 코어에는 별도 약관이 남아 있습니다.
원저자·구성요소 고지를 보존하며, 전체 수정 실행파일의 공개 재배포 조건은 추가 확인 중입니다.
ROM과 외부 BIOS는 제공하지 않습니다.
