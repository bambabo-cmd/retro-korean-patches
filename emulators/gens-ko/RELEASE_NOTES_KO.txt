Gens 2.14를 바탕으로 작업한 한국어 UI와 신규 기능 모듈의 시험 공개입니다.

공개 파일은 신규 기능 소스, 실제 설정 UI 구성 요소를 Windows에서 캡처한 화면,
짧은 게시판 안내와 SHA-256입니다. 전체 에뮬레이터 EXE와 게임 ROM은 포함하지 않습니다.

전체 수정 작업의 주요 변경
- 한국어 메뉴·설정창, XInput/DirectInput 패드와 일괄 키 설정
- Real CRT Phosphor v1.4.3 Gens용 GLSL 포트: 14패스, 실수 버퍼, 잔광
- 마스크·곡률·잔광·밝기 등 세부 설정과 프리셋별 저장
- GLSL/GLSLP 최대 16패스와 기본 효과
- 32MiB ROM·피어솔라 매퍼 대응
- FF·REW·슬로우모션, 기능별 홀드/토글과 속도 설정
- 기본 6버튼: ABC=CXZ / XYZ=DSA / START=V / MODE=F
- 창 전환·다중 모니터 출력 처리, Alt/Esc 메뉴, 게임 바로가기
- 기존 입력·저장·ROM 로딩·CPU 명령 등의 오류 수정

기본 핫키: Tab FF 홀드4배 / Backspace REW 홀드2배 / Space 슬로우모션 토글0.5배.
1배속 이외 재생과 REW는 무음이며, 메가 CD와 넷플레이의 REW는 지원하지 않습니다.

스크린샷은 실제 제품 설정 코드를 사용한 구성 요소 검증 도구에서 얻었습니다.
피어솔라 또는 전체 에뮬레이터의 실행 성공 화면으로 설명하지 않습니다.

전체 실행파일은 Starscream과 GPL의 별도 약관 문제를 해결한 것으로 표시하지 않습니다.
무료 배포와 소스 공개만으로 그 재배포 권한이 확정되는 것은 아닙니다.
