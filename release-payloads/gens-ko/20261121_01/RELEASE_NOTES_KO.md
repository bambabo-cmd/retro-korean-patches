# Gens KO 2.14 R3 test — Windows 실행판

Gens 2.14에 한글 메뉴, CRT 셰이더와 편의 기능을 추가한 비공식 포크 시험판입니다.

## 다운로드

**게임을 실행하려면 Assets의 `Gens_KO_2.14_r3_TEST_20261121_01_Windows.zip`을 받으세요.**

압축을 풀고 `Gens_KO.exe`를 실행하면 됩니다. 셰이더, 사용법, 라이선스 고지와 대응 소스가 함께 들어 있습니다. 소스만 필요한 경우 별도 `_source.zip`을 받으세요. GitHub가 자동으로 만드는 `Source code (zip)`은 실행파일 배포 ZIP과 다릅니다.

## 주요 기능

- 한글 메뉴·설정창, 키보드 및 게임패드 일괄 키 설정
- ROM 처리 상한 6MiB → 32MiB, 피어솔라 매퍼 대응
- FF·REW·슬로우모션, 기능별 속도와 홀드/토글 설정
- Real CRT Phosphor v1.4.3의 Gens 전용 GLSL 포트와 세부 설정
- Alt/Esc 메뉴 표시·숨기기, 게임 바로가기 실행
- 모니터 이동·창 전환 시 출력 처리 및 기존 입력·로딩 오류 개선

## 이번 수정 — 20261121_01

기존 저장 파일을 읽지 못했거나 일부만 읽었을 때, 빈 데이터로 기존 파일을 덮어쓰지 않도록 수정했습니다. 관련 63개 자동 검사와 대응 소스의 동일 실행파일 재빌드를 확인했습니다. 이 수정이 특정 사용자의 손상된 저장을 자동 복구하는 것은 아닙니다.

## 기본 키

| 기능 | 키 |
|---|---|
| ABC | C / X / Z |
| XYZ | D / S / A |
| START / MODE | V / F |
| FF | Tab — 기본 홀드, 4배속 |
| REW | Backspace — 기본 홀드, 2배속 |
| 슬로우모션 | Space — 기본 토글, 0.5배속 |
| 메뉴 표시·숨기기 | Alt 또는 Esc |

설정 → 키보드 / 게임패드 → **일괄 설정**을 누르고 안내 순서대로 입력하면 됩니다.

## 기존 사용자

먼저 `.srm`, `.srm.spi`, `.gs0` 등 기존 저장 파일을 다른 폴더에 복사한 뒤 Gens를 종료하세요. 기존 실행 폴더의 `Gens_KO.exe`를 교체하면 설정과 저장 경로를 유지하기 쉽습니다.

게임 내 저장 `.srm`은 ROM 파일명과 연결됩니다. F5로 만든 `.gs0` 등 빠른 저장은 F8로 불러옵니다.

## 배포 및 검증 범위

이 릴리즈에는 **Windows 실행파일과 전체 대응 소스**를 함께 제공합니다. 이전 검토 단계의 비공개 패키지 표기와 라이선스 검토 문서는 배포 ZIP에 과거 기록으로 남아 있습니다. 원저자 및 구성요소별 원문 고지를 보존합니다.

완전 무료·비상업 배포입니다. 동봉 셰이더 등의 비상업 이용 조건을 포함해 각 구성요소의 라이선스를 따릅니다. 게임 ROM과 외부 BIOS는 포함하지 않습니다.

시험판이며 실제 게임패드, 다중 모니터 및 게임별 장시간 플레이는 계속 확인이 필요합니다. 이번 저장 보호 검사는 생산 코드와 파일 API 대역을 이용한 자동 검사이며, 사용자 PC의 저장 파일 복구나 전체 Windows 게임 플레이 검증을 뜻하지 않습니다.
